# 選擇｜全螢幕彈力球互動動畫

整個視窗是球的容器。轉動裝置時，細點從手寫筆畫落下，碰撞合併成較大的球。90° 時可看見多顆球各自彈跳。160°～180° 期間，球逐步分裂並貼回筆畫，拼成倒置的「你就該完成我的夢想」。完整一圈後回到「我們都決定好了」。

## 開啟與操作

- 直接在瀏覽器開啟 `index.html`。可拖曳畫面、操作角度滑桿，或按「播放預覽」。
- 使用手機或平板時，按「啟用陀螺儀」，再把裝置正立並按「校正 0°」。瀏覽器可能要求動作感測授權，請使用 HTTPS 頁面。

## GitHub Pages

將 `index.html`、`README.md` 和 `.nojekyll` 一起上傳到儲存庫根目錄，並將 GitHub Pages 的發佈來源設為該分支的根目錄。

動畫程式和樣式都在 `index.html` 裡。手寫楷體使用裝置已安裝的字型。
